Scoreboard archive

The complete public scoreboard (every team and division), saved once per day: each day keeps the last board seen that day, so a competition day's file is the board as the round closed. This is what survives when the public scoreboard is taken down after the season. Files are gzipped JSON in the same format as the API, and a folder of them can be replayed in the dev container.
